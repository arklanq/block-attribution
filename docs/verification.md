# Verification log

Every mechanism Block Attribution relies on, with the evidence behind it. Verified on 2026-10-13 on macOS with Claude Code 2.1.296 (CLI and the Code tab of Claude Desktop), codex-cli 0.162.1, the Codex desktop app (ChatGPT.app 26.1007.30912, bundled codex 0.162.0-alpha.17.2) and git from Xcode.

Status legend: **Verified (test)** means observed on this machine. **Verified (source/docs)** means read in official documentation or in the tagged source code. **Unverified** means still an assumption.

## Not covered by any local mechanism

- Claude cloud sessions (claude.ai/code) and their PRs.
- Text appended to PRs by a server or GitHub App after the agent's command.
- Codex desktop `commit-tree` snapshots, unless pushed (then `pre-push` sees them).
- PR bodies created through the GitHub web UI.
